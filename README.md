# Curse of Armory [HC HAVEN SAKARYA]
Curse of Armory is a 2D platformer game that utilizes gun recoil to bounce around obstacles & enemies.

We made this in about 20hrs total for Hack Club Haven Sakarya

# How to Play
Curse of Armory is available to play on itch.io.

Controls:
WASD - Player movement
Arrow keys - Gun orientation / aim
SPACE - Shoot

Goal:
Find the Witch and get rid of the curse before sunset.
